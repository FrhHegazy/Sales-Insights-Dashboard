# Sales Insights Dashboard

An interactive Power BI project for exploring sales performance across products, customers, countries, and time.

## Overview

This project uses SQL Server to prepare and analyze sales data, then presents key trends and comparisons in Power BI. The SQL analysis includes top products by category, country-level sales comparisons, and each product's share of category sales.

## Project Files

- `Sales-dashboard.pbix` — Power BI dashboard
- `sql-script.sql` — SQL Server setup and analysis queries
- `Data/` — source sales, customer, and product CSV files
